# CPI Lens

美國通膨研究觀測站，深藍＋暖白 Liquid Glass 風格。資料截止 2026-10-15。

- `index.html`：依螢幕大小自動適配。
- `desktop.html`：寬版分析介面；小螢幕仍可閱讀。
- `mobile.html`：單欄手機閱讀版，桌面開啟時保留緊湊版型。
- `research-notes.md`：計算方法、2026 年權重與來源限制。
- `cpi-presentation.pptx` / `.pdf`：三頁財經分析簡報。

## GitHub Pages

從 main 分支根目錄發布。所有互動與樣式均內嵌，無需建置或外部程式服務。

數據為固定研究快照，非即時報價。核心年增預期 2.5% 為二手報導來源，原始調查未直接核實；情境分析不是數值預測。
